# Тренажёр задания 13 ОГЭ

Веб-тренажёр задания 13 ОГЭ по информатике. На экзамене участник выбирает одно из двух заданий —
оба есть в тренажёре на одной странице:

- **13.1** — презентация из трёх слайдов в LibreOffice Impress (файл `.odp`);
- **13.2** — текстовый документ с таблицей в LibreOffice Writer (файл `.odt`).

Работает в браузере, установка не нужна.

**Открыть:** https://yarclub2010-glitch.github.io/oge13/

Тренажёр задания 14 (электронные таблицы): https://yarclub2010-glitch.github.io/oge14/

Тренажёр задания 15 (исполнитель Робот): https://yarclub2010-glitch.github.io/oge15/

Тренажёр задания 16 (программа на Python): https://yarclub2010-glitch.github.io/oge16/

## Возможности

- **13.1 — как на экзамене.** Условие в формате ОГЭ с макетами слайдов, каталог с материалами для
  скачивания (текст по теме и шесть иллюстраций). Семь тем: басенджи (как в демоверсии 2026),
  бурый медведь, Байкал, подсолнечник, пингвины, вулканы, Луна.
- **Проверка презентации по критериям ФИПИ:** число слайдов, формат 16:9, анимация и смена слайдов,
  титульный слайд, заголовки, число картинок и текстовых блоков и их расположение по макету,
  единый тип шрифта (рубленый, с засечками, моноширинный), размеры 40/24/20 пт с учётом автоподбора,
  текст поверх картинок и слияние с фоном, искажение пропорций и наложение картинок.
  Однотипные ошибки считаются за одну систематическую, как в критериях. Схема слайдов показывает,
  как тренажёр прочитал файл, проблемные объекты обведены.
- **13.2 — восемь образцов**, первый — из демоверсии 2026. Проверяются все требования критериев
  к основному тексту и таблице: размер шрифта, заголовок прописными, выделение слов, междустрочный
  интервал, интервалы 14–24 пт до и после таблицы без пустых абзацев, выравнивание, отступ первой
  строки 1 см (не пробелами), разрывы строк и лишние абзацы, строки и столбцы таблицы, ширина и
  положение таблицы. Текст сравнивается с образцом: опечатки, пропущенные и лишние слова, пробелы —
  ученик видит свой текст с отмеченными ошибками.
- **Формат файла:** на экзамене .pptx и .docx получают 0 баллов — тренажёр так и оценивает, но
  показывает, сколько получила бы та же работа в .odp/.odt.
- Инструкции «как сделать в Impress/Writer», частые ошибки, справка, тёмная тема, телефон.
  Файл проверяется прямо в браузере и никуда не отправляется.

Ссылку на тему или образец можно отправить ученикам:
https://yarclub2010-glitch.github.io/oge13/#13.1/bear или https://yarclub2010-glitch.github.io/oge13/#13.2/demo

## Структура проекта

```
index.html            — страница тренажёра
src/
  main.js             — связывает всё вместе: вкладки, условия, материалы, загрузка, результаты
  tasks.js            — темы презентаций (13.1) и образцы текста (13.2)
  pictures.js         — иллюстрации для материалов (рисуются на canvas)
  slides.js           — чтение презентации .odp/.pptx: слайды, объекты, шрифты, картинки
  document.js         — чтение документа .odt/.docx: абзацы, интервалы, выделение, таблицы
  check131.js         — проверка презентации по критериям
  check132.js         — проверка документа по критериям
  textdiff.js         — сравнение набранного текста с образцом
  office.js           — общее: единицы, стили OpenDocument, связи OOXML, размеры картинок, типы шрифтов
  zip.js, xml.js      — архивы и разбор XML (из тренажёра задания 14)
  style.css           — оформление
tests/                — автотесты (открыть tests/index.html через локальный сервер)
tests/fixtures/       — файлы, сохранённые настоящим LibreOffice: верные решения и типичные ошибки
tools/make_fixtures.py — создаёт эти файлы через LibreOffice (UNO)
```

## Как добавить тему или образец

**Тема 13.1** — объект в массиве `TOPICS` в `src/tasks.js`: `id`, `title`, `folder` (имя каталога),
`about` (о чём сведения), `keywords` (слова темы), `text` (разделы `[заголовок, текст]`) и шесть
`pictures` — сцена из `src/pictures.js` и значки-эмодзи на ней.

**Образец 13.2** — объект в массиве `SAMPLES`: `heading`, `text` (абзацы), `table` (строки ячеек) и
`order` (`table-first` — таблица после заголовка, `text-first` — после текста). Выделение
размечается так: `**полужирный**`, `*курсив*`, `__подчёркнутый__`.

Автотесты проверят, что разметка закрыта и у тем есть все материалы.

## Запуск на компьютере для разработки

Дважды щёлкните `start-server.bat` (нужен Python) — откроется http://localhost:8000.
Отправить изменения на GitHub — `sync.bat`.

Пересоздать файлы для тестов (нужен LibreOffice):

```
"C:\Program Files\LibreOffice\program\python.exe" tools\make_fixtures.py
```
